# ADHD Flip Personalities

This is a beginner-friendly project made with HTML, CSS, and JavaScript.

It is an interactive flip card project based on ADHD-related traits. When a card is clicked, it flips to show a short and fun description on the back.

I made this project personal to me by using a neon green glow effect and concepts that reflect some ADHD traits in a fun and creative way. It is meant to be a light hearted project that while fun and simple also, teaches the beginner basic structure and some extra fun touches. 

## Features
- Click-to-flip cards
- Neon glow effect
- Grid layout
- Reset button
- Smooth flip animation

## How It Works
- **HTML** builds the structure of the cards and button
- **CSS** adds styling, glow, and flip animations
- **JavaScript** controls the click-to-flip action and reset button

## What I Learned
I learned how HTML, CSS, and JavaScript work together.

- HTML creates the layout
- CSS controls the design and animation
- JavaScript adds interactivity

This project helped me better understand how code files connect and work together to create something visual and interactive.
